# 自治体管理画面と開発用の後退

審査では[永続側の共通手順](local-api.md)で起動し、`/admin-local` を使う。以下の `/admin-demo` は開発用の後退で、新機能は追加しない。「今回の範囲」以降は未認証フォームの範囲・過去の検証記録。

開発サーバーを `npm run dev` で起動し、[/admin-demo](http://localhost:5173/admin-demo) を開く。ここではD担当のA03・A04・A05を試せる。A05での旅行者向け表示の確認は、管理画面内で完結する。旅行者向けの全国地図は `/` で開く。

`/admin-demo` は架空の自治体を使う**未認証の操作デモ**。実在の自治体への所属確認は行わず、実API、Firebase保存、Gemini、写真判定、公開処理には接続しない。画像を使うときは、権利を確認できるテスト用素材を選ぶ。

## 開発用の所属・問題・報告を閲覧する

[自治体画面のローカル検証手順](local-api.md#自治体画面をローカルで検証する)に沿ってWeb・API・所属を準備し、開発サーバーの `/admin-local` を開く。Googleログイン後、サーバーで本人確認が済んだら、所属する組織を選ぶ。自組織の問題名、状態、下書き版、公開版が表示される。開発用の公開担当者は「問題報告」も閲覧できる。永続モードでは報告をローカルのFirestoreに保存する。開発用の後退（`demo`）で報告を試す場合は `QUEST_REPORTS_MODE=memory` を設定する。

`/admin-local` の公開担当者は、公開中の問題で「公開を休止」を選び、対象の版と理由を確認して送信できる。版が変わっていた場合は最新の一覧を取得し、確認し直す。休止に成功すると一覧を更新する。

問題一覧で「下書きを新規作成」か「下書きを編集」を選び、A03/A04の画面に入力する。「下書きを保存」を押すと、自組織の下書きとして保存する（`durable-local` はFirestoreエミュレーター、`demo` は開発用メモリー）。以下のmemory設定は開発用の後退に限る。合成参考写真を使う場合は、`QUEST_ADMIN_ASSETS_MODE=memory` を設定し、写真の出典と利用権を入力する。

A03の利用時間は未設定・終日・時間指定・補足から選ぶ。時間指定は1時間刻みで、日をまたぐ場合は「終了は翌日」を選ぶ。以前に保存した曜日や自由記述は補足として編集できる。値は下書きとクリア後プレビューに反映する。

保存済みの版が変わっていた場合は、入力を残したまま上書きを止める。新規作成の結果が分からない場合は、問題一覧で確認する。

保存後に問題一覧の「撮影範囲を設定」から、非公開の地点と半径を編集できる。設定を解除するには範囲をすべて外して保存する。本文と同じ下書き版を使い、古い版への保存は止める。

「公開ヒント画像を設定」では、参考写真とは別の合成画像と、その利用権を入力する。保存した画像は次に公開する版へ反映される。外す場合は「参照を外して保存」を選ぶ。

A04の「保存済み版の候補を取得」は、永続側の通常起動で、保存済みの合成参考素材に対応する固定候補を取得する。メモリーデモの場合は `QUEST_ADMIN_DRAFT_MODE=fixtures` と `QUEST_ADMIN_ASSETS_MODE=memory` を設定する。承認後にVertexの生成試験を選んだ場合は、候補に出所が表示される。根拠を確認して「候補で編集欄を置き換える」を押し、内容を確認してから下書きを保存する。[Vertexの生成試験](vertex-trial.md#a04の合成生成を試す)

問題一覧の「試験と公開確認」から、保存済みの版に対してA05の写真試験を行う。合成素材の`match.png`で一致、`other-target.png`で別対象を確認し、A06で同じ版の確認を依頼する。公開担当者は両方の結果と確認待ち状態がそろってから5項目を確認し、「この版を開発用に公開」を押す。試験結果の選択は同じ画面内で保持されるので、一覧へ戻った後の公開には再試験が必要になる。[永続モードの試験設定](admin-photo-tests.md#永続の写真試験をローカルで試す)を参照。

認証なしの操作確認には `/admin-demo` を使う。[管理APIの接続手順](team-api-handoffs.md)

- 行き方・利用時間をクリア後の案内用として残し、地域のおすすめコメント・解説の入力欄を追加する。
- 公開探索エリアは自治体の行政区域から自動設定する構想。デモでは架空自治体のエリア名だけを示し、行政区域データの取得や地理的検証は行わない。
- 非公開撮影地点・半径は値を持たず、設定状態だけを示す。実際の設定・取得・所属認可は未接続。
- 参考写真を選択し、ローカルプレビュー、変更、削除ができる。ファイル形式・サイズの制限はデモのブラウザ保護用で、本番のO-03を確定するものではない。

- 非公開参考写真を公開ヒント写真に転用しない。公開ヒント用画像の作成・権利確認は後続の別工程。

## A担当との接続事項

既存の旅行者向け共通DTO・APIは変更しない。以下は管理APIを実装する前にA担当と共同で確定する。

1. サーバーで確認した所属・役割と、自治体行政区域から返す公開探索エリア。
2. `ManagedQuest` の下書き項目、船上・海上と有料施設内での撮影の必須条件、事前の料金・撮影注意、クリア後用のアクセス・利用時間・自治体コメント・解説、出典・権利情報の契約。既存の交通手段配列を新たなAPI契約として採用しない。
3. 参考写真の用途別assetId、認可付き取得、形式・容量・内容検査。参考画像と公開ヒント画像は別用途で管理する。
4. 非公開撮影範囲の設定状態と、認可された設定操作。公開DTOに座標・半径・参考写真を混ぜない。
5. 下書き保存・競合検出用revision、エラー・再試行、AI生成依頼の接続。フォームの値を所属や権限の根拠にしない。

## A04の編集と素材の保持

現在のフォームはローカル表示用の状態で、API契約ではない。親の管理デモがA03・A04の状態を保持し、往復しても素材入力・参考写真・編集した文章を保持する。画像URLはステップ切替では解放せず、写真の置換・削除・親コンポーネントの破棄で解放する。実保存を追加する際は、破棄・保持の説明とテストを同時に更新する。

A03で対象名・対象にした理由を入力してからA04へ進む。空白だけの入力も未入力として扱い、対象名または理由が不足するとエラーへフォーカスする。A03の「入力内容を確認」でも同じ必須入力を検査する。参考写真を選ぶとファイル名とプレビューを表示し、変更・削除できる。同じ写真を再選択する操作にも対応する。料金欄には入力例を示す。

クリア後の自治体紹介コメントと解説はA03で手入力し、A05のクリア後表示で確認できる。編集する場合はA03へ戻る。紹介・解説を生成するAI APIは未提供のため、フォーム上でもその旨を明示する。A04の候補生成は問題文などの候補に限られ、合成固定候補または設定済みのVertex試験の結果を人が確認・編集してから保存する。架空サンプルはAI生成ではなく、登録素材から事実を推論・検証するものでもない。編集済み内容へのサンプル再読込は、置換の確認・取消を挟む。

A03の素材を変更しても既存の文章は上書きせず、素材との再確認が必要なことをA04で知らせる。根拠・出典は人が確認する材料で、入力しただけで安全・権利確認や正解の検証が完了したと扱わない。参考写真をA04のヒント画像へコピーせず、ヒント画像は未設定として示す。

将来のAI接続では登録済みの確認材料から生成し、結果は検証・編集が必要な下書きとして扱う。参考写真を公開プレビューへ自動表示せず、A05の試験で旅行者の発見記録を作らない。生成・試験・公開の成功表示は各サーバー処理の実装と検証後に追加する。

## A05 管理画面内の旅行者向け表示確認

A04から表示プレビューへ進み、「挑戦前の問題」と「クリア後の解説（デモ）」を分けて確認する。挑戦前は問題タイトル・問題文・段階ヒント、架空の公開探索エリア、料金・撮影上の注意を表示し、問題の端に選択した撮影条件のアイコンと意味を示す。船上・海上と有料施設内は独立に選択でき、両方選択も可能。場所までの移動手段を表すものではなく、その条件で撮影しないと対象を撮れない場合に選ぶ。未選択を無料・陸上撮影可能との保証として扱わない。

クリア後用の行き方・利用時間・地域のおすすめコメント・解説は、専用の表示確認でだけ確認する。管理用の切替であり、実際にクリアしたことや閲覧権限を証明しない。撮影可能時間や安全・通行の制約は「撮影時の注意」に入力し、挑戦前に知らせる。

ヒントは個別に開閉でき、未入力の項目は未入力として示す。A04へ戻って編集でき、再度プレビューすると最新の入力を反映して挑戦前表示・ヒントを閉じた状態から始める。未入力でも表示の確認はできるが、公開可能との判定ではない。

各プレビューコンポーネントには表示対象の項目だけを個別に渡す。挑戦前のコンポーネントにはアクセス・利用時間・自治体コメント・解説も渡さない。管理内部の対象名・根拠・確認済み特徴・人のメモ・写真の出典と権利・参考写真のFileやURL・非公開設定は両方の表示確認から除外する。全てのフォーム状態を公開データとして扱わず、公開ヒント画像には参考写真を流用しない。A03〜A05の切替で入力・写真・文章は保持し、写真のURLは切替だけで解放しない。

画面は管理用の未公開プレビューと明示する。実際の旅行者画面、実API、カメラ・位置情報、写真判定、試験成功、保存・公開には接続しない。表示内容を手動で確認したことを、正解判定や公開前試験の合格として記録しない。

後続の写真判定試験と公開はA担当との接続事項。素材や文章を変更した後に過去の試験結果を有効と扱わない契約を共同で確定する。
