# 永続側の撮影範囲・時間・料金・写真権利入力

2026-11-08。FR-09/12、A03〜A06、AT-13/15/16/21/22/25に関連する入力支援。`durable-local`の管理画面を対象とし、旧メモリーデモと`/admin-demo`に新しい入力支援は追加しない。

## 撮影できる範囲（非公開）

所属認可済み管理APIから取得した範囲だけを専用地図へ渡す。地図クリックで新規範囲または選択範囲の中心を指定し、半径1,000mの円で確認する。旧半径の下書きは明示操作で確認・更新する。最大10件、追加・削除・全解除・明示保存、`expectedDraftRevision`の競合処理を維持する。[行政区域・対象スポット・固定半径](admin-municipal-locations.md)

設定がない場合やロード・認証失敗時も数値入力を使える。通信失敗は再試行できる。編集時は地図インスタンスを維持し、パン・ズームをリセットしない。施設・住所検索、EXIF位置取得、ドラッグによる半径変更は追加しない。対象の所在地と撮影者の立ち位置を区別し、地点を選んでも写真権利・安全・通行許可を確認済みにしない。

非公開値を公開探索地図・公開区域・通常ヒントのDTOに追加しない。地図を表示した場合は既存のMaps SDKが外部通信するが、今回のローカル検証ではloaderとSDKをモックし、外部通信は実行していない。サービス追加・キー取得・課金変更はしていない。

## クリア後の時間案内と挑戦前の料金

時間は端末標準の`input type="time"`で分まで指定する。開始・終了・翌日と「曜日・休業・例外」を同時入力でき、終日にも例外を併記できる。未設定と終日は別。営業時間などの一般案内は引き続きクリア後だけに表示し、撮影可能時間の制約は挑戦前の`materials.photoNote`へ人が記載する。

保存は既存の`afterClear.hours`文字列。操作しない既存値はそのまま保存する。既存の複雑な自由文は「補足を入力」で編集できる。正規形式の分入り時刻は構造入力に復元する。旧`24:00`は表示上「翌日00:00」に対応させ、無操作保存では元の文字列を維持する。新しい通常時間と例外は改行で連結する。

任意案内の途中入力で文章編集やプレビューを妨げない。開始のみなら`22:15〜（終了未設定）`、終了のみなら`（開始未設定）〜17:45`、翌日指定のない逆転時間には`（前後関係を要確認）`を明記する。空欄を終日へ変換しない。これらは時間制限や営業時間の機械判定ではなく、そのまま読める任意案内として保存する。再表示時には自由文として保持される。公開前に内容の確認を促し、公開確認の訪問条件チェックは残す。

料金は未設定・自由文／無料／有料／未確認を選べる。区分を変えても既存の大人・子供別金額などの補足を保持する。金額・条件は必要時に編集する。空欄を無料にしない。有料施設条件チェックとは独立し、料金選択で安全条件を自動設定しない。

strict schemaのキー、型、最大長を変更しない。時間・料金は各2000文字以内という既存境界で保存を検証する。サーバーの自由文検証・公開資格を迂回するダミー値や未定義キーは使わない。途中状態を専用JSONへ拡張する案より、既存データを無損失で読める文字列契約を維持する小さい設計を選んだ。

## 用途別の写真権利入力支援

参考写真（非公開照合）・ヒント（公開）・試験（非公開）にそれぞれ選択支援を置く。根拠は初期未選択。「自分で撮影／自治体所有／許諾あり／その他の権利根拠」と撮影者・所有者・許諾元・利用条件を入力し、その写真を当該用途に使えることを人が確認した場合だけ「権利文に追記」できる。既存自由文は維持し、追記する文も事前表示する。文の生成は権利の証明ではない。別写真・別用途・別組織の権利を暗黙にコピーしない。写真差し替え時も文は消さず、新しい写真への適用確認または権利文の明示編集・追記が済むまで送信を止める。

権利文は既存の`photoRights`へ渡す。素材用途、所属、公開担当者、画像検証、必須権利、冪等キーと回数制限は既存サーバー経路が検証する。写真自体の再利用機能・素材ライブラリ・AIによる権利推定は追加しない。参考写真全景を公開ヒントへ自動流用しない。
