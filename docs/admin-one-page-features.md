# 管理の問題作成：機能一覧

変更前の AdminQuestWorkflow と配下を確認した一覧。永続側が対象。API・認可・公開条件は変更しない。

| 範囲 | 維持する入力・表示・操作 |
|---|---|
| 対象 | 撮るもの、正解の写真、形式・容量エラー、選択写真プレビュー、変更・削除・読込失敗の再試行、保存済み写真の参照を外す |
| 場所 | 所属自治体の探索エリア、取得失敗、行政区域出典、地図選択、スポット名・住所・座標、住所候補と確認、撮影範囲の自動保存 |
| 条件 | 船上・海上、有料施設内、料金区分・金額・補足、撮影の注意、よくある注意の入力支援 |
| クリア後 | 開閉、行き方、交通手段・所要分数から文を作る、利用時間の区分・開始・終了・翌日終了・補足、紹介、解説 |
| 本文 | タイトル、問題文、ヒント1〜3、特徴、特徴を1行で追加、必須入力・特徴の行数と長さのエラー。旧根拠・メモは非表示のまま保持 |
| 下書き案 | 保存済み版から取得、待機・失敗・競合、案の出典と内容、反映する項目の選択、編集欄への取り込み、未保存表示、元に戻す |
| 保存 | 新規作成・更新、参考写真アップロード、保存中の操作抑止、保存済み表示とフォーカス、入力エラー、通信失敗・競合・新規保存結果不明時の再作成防止 |
| ヒント画像 | 保存済みヒント1〜3の表示、設定先選択、画像選択、形式・容量エラー、未入力表示、画像保存、選択取消、各画像を外す、保存中・完了・失敗 |
| 写真試験 | 保存済み版の不足項目と入力欄への移動、読込・再読込・競合、合成写真の制限と一致用・別対象用ダウンロード、正解写真・別写真の選択と試験、形式・容量制限、判定中・一致・別対象・不能・相違・通信障害・回数制限、同じ写真で再送、写真変更時の証跡破棄、保存版変更時の再試験 |
| 公開 | 地域未設定時の制限、両写真試験完了の前提、確認依頼、公開確認ダイアログ・取消、公開・修正を公開・公開を再開、失敗表示、公開後の一覧更新 |
| 移動・保護 | 謎一覧へ、下書き・公開中・休止中の状態表示、未保存離脱の保存して移動・保存せず移動・とどまる、Escape・Tabのフォーカス制御、ブラウザ離脱警告、旧step URL |

休止操作自体は問題一覧側にあり、このフォーム配下にはない。従来どおり一覧から実行する。工程の次へ・戻るは縦スクロールに統合する。本文の保存は既存の下部保存バーに1つ、画像の保存は別素材を保存する操作として残す。
