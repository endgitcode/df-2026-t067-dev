# 自治体管理画面での写真利用

永続ローカル・共有検証の4ステップでは、担当者が照合や公開に使う許可を得た写真を選ぶ。参考写真・公開ヒント画像・写真試験のための `adminPhotoApprovals` 登録と、公開前のチェックボックスは不要。参考写真は非公開のまま扱い、公開用のヒント画像は別に選ぶ。サーバーは所属と素材の用途を照合し、公開ヒントと参考写真が同じ画像なら公開を拒否する。

1. STEP 1で対象スポットと参考写真を保存する。撮影範囲はスポットを中心に半径1kmで設定される。
2. STEP 2で料金と撮影条件を確認し、STEP 3で問題文、ヒント3つ、照合に使う確認済みの特徴を保存する。ヒント画像は任意。
3. STEP 4で同じ対象の一致写真と、別の対象の写真を個別に送信する。合成試験の環境では画面の合成画像を使い、参考写真に一致用を登録する。実写真の照合は実Vertex試験が有効な環境で行う。
4. 両方の試験が成功したら「この版を公開」を押す。公開操作の中で保存済みの入力条件を確認する。サーバーは確認済みの下書き版、参考写真の保存世代、異なる写真による一致・別対象の結果、所属、地域の分類などを確認する。

STEP 4は同じ下書き版を開いている間、工程移動の前後で試験結果を保持する。下書き版が変わると再試験が必要。再ログイン・再読み込み後の証跡復元は未実装。

旧版の `photoRights` や `confirmations` を送るクライアントとの互換性を維持する。写真を候補生成に使う別機能の事前承認は従来どおり。既存の承認記録や公開済みの版に対する移行作業は不要。
