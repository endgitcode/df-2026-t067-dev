# 自治体の登録フォームの入力案内

対象は `QuestDraftForm` と共通の文章編集・プレビュー部品。永続側の `LocalAdminWorkspace` と開発用 `/admin-demo` の両方に適用する。API・保存形式・確認依頼・公開条件は変えない。

- 手順名は「1/3 素材と場所」「2/3 問題の文章」「3/3 表示プレビュー」。内部の画面ID A03〜A05 は仕様・テスト上で維持する。
- 永続側（タスク型）では対象名が未入力でも文章編集へ進める。対象名は公開までに必須。接続版・旧デモでも次の文章編集へ進む際に必須なのは対象名だけとする。対象理由の入力欄は廃止済み（D-16）。保存済みの理由は互換のため残置し、フォームでは表示・編集しない。下書きは空欄でも保存できる。未入力欄にはエラーを関連付け、最初の不足欄にフォーカスしスクロールする。
- 参考写真は後から登録できる。接続版で新しい写真を添えて保存する場合は出典・利用権が必須。権利欄は写真の直後に常時表示し、保存時の不足はその欄へ誘導する。
- 安全条件・料金・撮影注意は挑戦前に公開する入力として常時表示する。安全上の制約があれば記載する案内を保持する。
- クリア後のアクセス・時間・紹介・解説は任意の折りたたみ内に置く。開閉と手順往復で入力を保つ。旧デモは時間指定の整合性検証を維持する。永続側は[入力支援](admin-input-ux.md)に従い、任意時間の途中状態を明記して保持する。
- 対象名・照合用写真・権利・確認済み特徴・人のメモは非公開。タイトル・問題文・段階ヒントは公開文章、紹介と解説はクリア後の公開文章として区別する。確認済み特徴は確認依頼までに必須、人のメモは任意。
- 未完成でもプレビュー可能。タイトル・問題文・ヒントごとの不足を示し、文章または素材の編集へ戻れる。文章編集への戻りでは素材の不足を理由に別の画面へ移さない。プレビューは公開資格を保証しない。
- 問題一覧の「公開準備」には、保存済みデータから算出した残りの作業（対象名・権利・参考写真・撮影範囲・本文・特徴と、状態に応じた確認依頼／公開担当の確認）を表示する。写真試験の実施状況は画面内保持で一覧からは判定できないため、実施済み・未実施として断定せず、その旨を明記する（D-17）。
- 撮影範囲は永続側と共有サイトで地図でも設定できる。地図が読み込めない場合や設定がない場合は数値入力で完結する（D-17）。
- 写真試験は合成フィクスチャ専用であることを画面に明示し、一致用・別対象用の合成写真をその場でダウンロードできる。実写真では結果が記録されない（D-17）。
- 編集担当にも公開担当者の確認欄を読み取り専用で表示し、公開は公開担当が確認・実行すること、写真試験は公開担当の画面で再度実施が必要なことを示す。権限と公開可否は変えない（D-17）。

## 回帰条件

FR-09/12、AT-13/15 の管理入力・確認に関する部分検証の補足（受入全体の完了を意味しない）。`RegistrationUx.test.tsx` で欄別エラーとフォーカス、最小入力からの文章編集、折りたたみと往復による値保持、未完成の不足表示、接続版の全フィールドの保存payload一致、時間エラー時の再展開、写真の権利エラー時の欄への移動を確認する。

既存の `QuestDraftForm.test.tsx` は折りたたみを明示的に開き、内部番号の表示期待とエラー移動先の期待を更新する。AI候補、参考写真、ヒント画像参照、下書き保存の競合処理は既存テストを維持する。実認証・実API・実端末での確認とは区別する。

永続側の一件編集では、保存成功後に撮影範囲・指定ヒントの画像・試験と公開確認へ進める。一覧を経由せず本文へ戻り、最新revisionを再取得する。通常フォームから人のメモを外すが既存値は消さず、候補採用でも保持する。紹介入力方法の未提供ラジオと重複する素材要約操作は永続側から外す。既存自由文の保持を維持する。永続側の分・例外入力、料金選択、用途別写真権利、管理地図は[入力支援](admin-input-ux.md)を参照。
