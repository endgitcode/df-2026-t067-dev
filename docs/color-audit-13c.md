## 1. コントラスト

WCAG 2.xの式：sRGB値を255で割り、0.04045以下は12.92で割り、それ以外は `((c + 0.055) / 1.055)^2.4`。相対輝度 `L = 0.2126R + 0.7152G + 0.0722B`、比は `(明るいL + 0.05) / (暗いL + 0.05)`。判定は丸め前、表は小数2桁。通常文字4.5:1、大きい文字・アイコン・必要な枠3:1を基準とする。

今回の対象で使う組み合わせ（—は対象の通常文字として使っていないもの）。旅行者側は既存の変数上書きで黒が #000000 になるため併記する。

## 3. 色の意味と修正

- 水色の重複：確認待ち・判定待ちを既存の灰色へ修正し、選択中と分離した。
- 未確定の受付結果が既定のピンクになっていたため、data-outcomeなしは灰色へ修正した。成功は緑、対象不一致・処理エラー等はピンクのまま、個別の結果文で区別する。
- 地図現在地・ズームのホバーは緑から薄灰へ、開いた問題ボタンは緑から白へ修正した。撮り直しの旧ホバールールも薄灰へそろえた（後段の白上書きは維持）。
- 黄を外したプレビュー表示、地図ラベル、カメラ、注記、管理の非公開設定・確認欄等は白地と既存の文字／枠を維持。主ボタンは黄、公開・成功・保存は緑、エラーはピンク、下書き・休止は灰色を確認した。

直していないもの：地図背景は引き続き水色。選択UIは黒枠・太字・ariaで区別する。スマホナビ・既存の工程／ヒント選択は従来の太字・下線・aria等を維持し、水色への全面変更はしていない。既存のスケルトン等の緑、クリア演出の装飾色、既存のフォーカス色も今回の差分外として変更していない。地図ピンのクリア色、一覧クリア済みの✓追加は機能・アイコン変更になるため実施していない。
