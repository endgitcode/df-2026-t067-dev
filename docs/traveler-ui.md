# 旅行者向けUIの現在の範囲

2026-11-05。ユーザーが選んだNeobrutalismの方向で、旅行者画面と自治体デモのUIを揃えた。全国地図を入口にする構成、アプリ名、製品要件、既存の認証・撮影・API処理は維持する。

## 共通の表示ルール

- `src/theme.css`で色・枠線・角丸・影・文字の強弱を共有する。生成りの背景に黒い2pxの枠線、黄色の主操作、黄緑の問題見出し、水色の地図を使う。
- 操作ボタンは44px以上を基本にし、押すと影に沈む表現にする。無効な操作は灰色で区別し、キーボードのフォーカスは青い輪郭で示す。動きを減らす設定では移動を止める。
- 地図、問題詳細、地域・問題の選択、ログイン状態、撮影・写真確認、取得中・0件・失敗・再試行を同じ配色に揃える。
- `/admin-demo`の素材登録・下書き編集・旅行者向け表示確認も同じテーマを使う。デモ・未接続の注意や非公開情報の扱いは変えない。
- Google Mapsを表示する場合もGoogleの地図表示・帰属表示を覆わない。新しい依存や外部フォントは追加しない。
- 重複するキャッチコピーや補足は減らし、見出し・配置・余白で構造を伝える。入力ラベル、アクセシビリティ用の説明、エラー、権限、デモの注意は残す。スマホでは地図操作ボタンがデモの注意文に重ならないように配置する。

## 使える操作

- 公開APIから取得した問題一覧で1問を選び、詳細を開く。ローカルAPIは架空の3問を返す。APIモードでは固定デモマーカーを表示しない。
- 「公開情報を更新」から公開・休止後の地域・問題一覧・選択中詳細を取り直せる。地域と問題IDを保ち、失敗時は再試行できる。選択中の問題が消えて別問題へ切り替わった場合や、同じ問題の新しい版を取得した場合は画面で知らせる。更新中は重複操作を抑止する。
- 「全国」または公開地域を選び、地域ごとの公開問題に絞り込む。地方→都道府県の順でも絞り込め、地図の上部に浮くチップで選ぶと地図のマーカーと問題一覧がその範囲に切り替わる。都道府県コードの無い地域は「未分類」から選べる。地域名と問題数を表示し、0件でも別地域や全国へ戻れる。
- Google Maps上で日本周辺を移動・拡大縮小し、初期表示に戻す。durable-localでは公開探索地域の境界を表示し、地図または地域選択から問題一覧を切り替える。問題座標やdemoの架空データは地図へ送らない。
- 未ログインで問題を閲覧し、挑戦ボタンから既存のGoogleログインを開始する。取消・失敗でも問題を保持し、ログアウトもできる。
- 段階ヒントの404または入力エラーでは、利用者が「問題を読み直す」を選んで公開情報を再取得できる。通信失敗・タイムアウトはヒントの再試行を案内し、問題の版変更（409）とは区別する。
- 段階ヒントは最初に1つ目だけを表示し、取得成功後に次の番号を表示する。開いたヒントを閉じても解放済みの番号は使え、詳細を閉じる・問題や版を切り替えると最初からになる。ヒントとヒント画像の操作ボタンはログアウト等と同じhover/press表現を使い、動きを減らす設定では動かさない。
- 地図は画面いっぱいに広げ、表示範囲に連動する問題カードは下端のボトムシート（覗き見／半開き／全開、ドラッグとタップで開閉）に入れる。シートはドラッグで完全に閉じられ、閉じると灰色の取っ手も隠れる。地図上に残る独立した「謎リストを開く」ボタンから再表示する。スマホでは拡大・縮小・表示リセット・現在地の各ボタンを下部タブバーと閉じたシートの復帰ボタンより少し上の同じ位置に固定し、シートを開くと背面に隠す。地方・都道府県フィルタと地域名チップは同じ縦積み領域に置き、フィルタが1段でも2段でもチップが重ならないようにする。シート表示の間は幅を問わずステージの高さ上限と枠を外して表示領域全体（100dvh）を占める縁なし配置にし、ヘッダー・ナビの帯を無くしてアプリ名・記録・ログイン等の導線を地図の上に浮かせる（D-26）。シートはPCでは最大幅付きで左下に置き、問題詳細は地図の下に読みやすい幅で置く。地図が使えない場合は縁なしにせず従来の通常フローのままにする。キーボードのフォーカス、本文への移動、動きを減らす設定に対応する。

認証の設定手順は[Firebase接続ガイド](firebase-auth.md)を使う。実設定は`.env.local`だけに置く。

## デモと未実装の境界

`VITE_GOOGLE_MAPS_API_KEY`を設定すると、Google Maps JavaScript APIから地図を読み込みます。キーがなければ設定を案内し、読み込みに失敗した場合は再試行の方法を表示します。どちらの場合も問題は閲覧できます。[Google Maps接続手順](google-maps.md)

公開APIのdemo応答は架空の問題・地域です。demoモードでは地図に地域境界・マーカーを描画しません。durable-localモードでは公開APIの公開探索地域GeoJSONだけを表示し、クリックで地域選択を同期します。問題位置・正解位置・参考写真は地図に渡しません。地図表示のために位置情報の許可を求めることもありません。

開発画面では公開APIから問題一覧、詳細、地域名を取得する。失敗した場合は、固定の`demoQuest`へ切り替えずに再試行を案内する。開発用の合成記録を設定すると、「自分の記録」で閲覧や削除を試せる。[本人記録API](owner-discoveries.md)

APIモードでは、サーバーでログインを確認した後、利用者の操作で撮影、写真確認、写真とGPSの開発用送信を試せる。この画面からの送信は開発用の受付までで、実写真の照合や記録の永続保存は未接続。[撮影と写真確認](camera-preview.md)

T02は共通型`PublicQuest`を表示する`QuestDetails`へ分離済み。認証後に問題ID・版を渡す接続口を用意する。最新mainのChallenge作成APIと撮影入口を維持し、APIモードでは選択中の問題ID・版で開始を確認してから撮影へ進む。判定・保存は未接続。ローカル公開APIの応答自体は架空データ。全国地図は問題座標と連動しない。詳細と検証範囲は[B担当の実装範囲](b-development.md)を参照する。

B担当が実地図へ接続する際も、[共通API](api.md#8-最初の共通api実装)の公開探索エリアの代表点と非公開の正解地点を分ける。旧デモの表示位置を実データとして流用しない。

## 地形の出典

旧SVG素材はNatural Earthの1:110m国境データから作成した静的プレビューでした。現在の画面では使用せず、素材ファイル（japan-overview.svg／japan-overview-wide.svg）は削除済みです。

低解像度の概観であり、小島や境界の精密な表示には使わない。正解位置、実写真、個人の行動履歴は含まない。コンパス等の小さなアイコンはコードで作成し、外部画像や新しい依存パッケージは追加していない。

## 確認範囲

`npm run check`で型・lint・自動テスト・ビルドを確認する。最新の件数と実施結果は[B担当のPRレビュー記録](b-development.md#pr-32のレビュー最終確認)に記載する。API取得、地域絞り込み、0件・失敗・再試行、古い応答の破棄、問題ID・版の引き渡しをテストする。Mapsキー未設定時にも問題閲覧を続けられ、架空マーカーを作らないことを確認する。

Google Mapsローダーのキー注入・script共有・callback、通信失敗後の再試行・タイムアウトの後始末、認証失敗表示の維持は外部通信なしでテストする。ヒント404・入力エラーからの手動更新と更新後のフォーカス復帰もモックAPIで検証する。実API、実地図表示、Cloud設定、実スマートフォンは未検証。
